# 선행연구 분석 실습 교안

연세대학교 BK21 대학원생 워크숍(2026년 11월)에서 쓰는 웹 교안입니다.
학술 DB(Web of Science, Scopus, DBpia)와 Claude로 선행연구를 따라가며, 내 핵심 연구 질문 하나를 찾습니다.

**교안 열기: https://modulabs.github.io/yonsei-bk21-research-lms/**

## 이 교안으로 하는 일

- 세부 단계마다 먼저 내 생각을 적으면, 적은 내용이 프롬프트 빈칸에 들어갑니다.
- 완성된 프롬프트를 복사해 Claude Code에 보냅니다. 같은 프롬프트를 샘플 주제로 채운 예시와 결과도 볼 수 있습니다.
- Claude가 제시한 '이어서 물어볼 질문' 가운데 하나를 고르거나 직접 쓰고, 왜 궁금한지 적으면 그 단계를 완료할 수 있습니다.
- 완료한 단계는 진도율에 반영되고, 단계별 결과와 고른 질문은 '내 연구 질문 패키지'에 모입니다.

## 입력 내용 저장

- 적은 내용은 지금 쓰는 브라우저에만 저장됩니다. 서버로 전송되지 않습니다.
- 브라우저 기록을 지우거나 다른 기기로 옮기면 사라집니다. '내 기록 내보내기'로 마크다운 파일을 내려받아 작업 폴더에 보관하세요.
- '백업 파일 저장'과 '백업 불러오기'로 다른 브라우저에서 이어서 할 수 있습니다.

## 샘플 연구

교안의 예시는 한강 『채식주의자』의 여러 언어 번역본과 기계 번역·AI 번역 비교를 주제로 실제로 수행한 샘플 연구 기록입니다.
샘플은 따라 할 정답이 아닙니다. 같은 프롬프트에 다른 주제를 넣었을 때 어떻게 바뀌는지 보여 주는 사례입니다.
화면 캡처의 계정 정보는 흐림 처리했습니다.
